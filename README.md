# Plumb

Open source spec-driven development (SDD) harness for AI coding agents.

Works with Claude Code and Cursor today, in any language. The agent drives,
the harness guides, the human approves.

> Status: early scaffold. See `docs/` as it grows and the phase checklist in
> `.claude-harness/` for what's implemented so far.

## Quickstart

```bash
npm install -g plumb-harness   # once published
plumb init                     # inside a git repo, once per project
```

## Development

```bash
npm install
npm run dev -- status
npm test
```
